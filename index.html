N-ZONE Guard

Network Zoning Operation & Naming Guard
SAN 조닝의 반복 작업을 자동화하고, 사람이 놓치기 쉬운 Naming · Index · WWPN · CFG 간 불일치를 사전에 탐지하는 업무지원 도구입니다.

100%Offline
0Credential Stored
RuleBased Validation

왜 만들었나

SAN 조닝은 규칙이 명확한 대신 작은 오타가 작업 오류로 이어질 수 있습니다. 반복 입력은 자동화하고 사전 검증을 표준화합니다.

무엇을 검증하나

S/D Index와 Member 일치, 관리번호, Storage Port, WWPN 형식, cfgadd 누락, Switch_CFG 일치 여부를 확인합니다.

안전 설계

Switch 자동 실행 기능을 제외하고 Script 생성과 검증에 집중하여 운영 리스크를 낮추는 구조로 설계했습니다.
